## First Principle
This is not a website. It is a place.
A ceremonial place. A digital sanctuary. A sacred place. A contemporary sanctuary. A threshold.
A place where people arrive differently than they leave.
Every page should feel like entering sacred ground.

We do not design pages. We shape places.
We do not build interfaces. We shape living worlds.

The interface should disappear. The experience should remain.

Atmosphere is the medium.
Presence is the outcome.

Every design decision should strengthen this illusion.

## Identity
Cinematic ceremonial digital environment. NOT startup / SaaS / wellness app / coaching / retreat marketplace.
Focus: THE PROJECT, THE FIELD, THE EXPERIENCE. Yakov = founder, guide, architect. Not guru, not influencer.

The project should never feel like:
- software
- SaaS
- a travel website
- a luxury hotel
- an online course
- a marketplace
- a commercial landing page

It should feel like entering a sacred landscape.
Silence is part of the architecture.
Atmosphere is part of the interface.
Presence is the primary feature. Everything else is secondary.

## Visual Language
Sacred minimalism. Cinematic editorial. Luxury restraint. Atmospheric depth. Modern temple aesthetics.
Feel: expensive, calm, timeless.

## No Global Visual Rules
No visual treatment is universal.
Every page, every section, and every transition must be evaluated individually.
Never apply an effect globally simply because it exists elsewhere in the project.
Every visual decision must be justified by composition — not by precedent, not by "that's how we did it last time."

## Composition First
Composition has higher priority than visual effects.
Always solve problems in this order:
1. Composition
2. Layout
3. Photography
4. Typography
5. Materials

Only after these five are correct may decorative effects be considered.
Never use gradients, blur, overlays, glow, or masks to compensate for weak composition. If a section feels wrong, fix the composition — don't dress it up.

## Art Direction Hierarchy
Every visual decision follows this hierarchy:
1. Composition
2. Photography
3. Typography
4. Material
5. Motion
6. Effects

Effects sit at the bottom for a reason: they are the final layer, applied last, and only when everything above them already works. They must never become the primary visual language of a page.

## Restraint
When uncertain, remove visual elements instead of adding new ones.
The Open Sky grows stronger through restraint, not decoration.
This is the same law as Editing Rule and When Uncertain further below — stated here first because it governs everything that follows.

## Forbidden
- Startup/SaaS UI patterns, generic Tailwind, loud gradients, neon, psychedelic clichés
- Overanimated interactions, card grids, template feeling, AI luxury sameness
- Marketplace/catalogue/coaching energy, generic wellness design

## Design Anti-Patterns
Concrete mistakes this project makes when it drifts — not generic advice.
- Never end a Hero with a hard black gradient. A dissolve is one option, not the rule — see Section Transitions.
- Never let UI compete with photography. If in doubt, remove the UI element.
- Never give multiple CTAs equal visual weight. One primary invitation per view.
- Never let a Journey Card carry a price badge, star rating, or "Book Now" button — that's booking-card aesthetics, not a ceremonial invitation.
- Never let cards read as a catalog grid. If it feels like scrolling a shop, it's wrong.
- Never introduce a new component when an existing one (Hero, Journey Card, CTA, Gallery, Testimonials, Guide, Timeline) can evolve instead.
- Never sacrifice whitespace to fit more content. Remove content before you compress spacing.
- Never fake depth with a drop shadow. Use spacing, contrast, and atmosphere.
- Never blend two destinations' palettes inside one section — one destination, one emotional palette.
- Never let a testimonial look like a review-site quote (avatars, star icons, verified badges).
- Never let navigation or overlay UI compete with the Hero photograph for the eye's first landing point.

## Colors
Palette: warm ivory → parchment → champagne → muted gold → warm graphite → deep bronze → warm black.
Accents: sacred amber, sunlight gold, soft bronze.
Tonal arc: pages tend to feel lighter/airier near the top and deeper/more cinematic toward the bottom — a palette tendency, not an automatic gradient mechanism. Whether and how a given page expresses this is a per-page composition decision — see No Global Visual Rules and Section Transitions.
Avoid: pure white, cold grays, bright blues, purple gradients.

## Material Language
Every page should feel inspired by physical materials, not by software.
Primary materials: stone, linen, aged paper, bronze, wood, snow, mist, sunlight.
- Avoid glossy digital surfaces.
- Avoid plastic UI.
- Avoid futuristic materials.
Surfaces should read as touched by hand or by weather, never manufactured.

## Light System
Treat light as a material, not a lighting effect.
Preferred:
- atmospheric haze
- natural gradients
- ambient light
- soft depth
- subtle bloom
- layered shadows
Avoid:
- black overlays
- artificial glow
- neon
- strong vignettes
- high-contrast overlays
This governs the tonal arc described under Colors: where a page does darken toward the bottom, the darkening should read as atmosphere, not a lighting trick — and per Section Transitions, that's still a per-page decision, never an automatic mechanism.

## Typography
High-end editorial serif. Cinematic luxury hierarchy. Headlines: large, cinematic, intentional.
Micro labels: uppercase, tracked, minimal. Avoid startup/trendy fonts.

## Layout
Massive spacing. Breathe. Every section = a chapter. Avoid dense layouts, boxed UI, uniform sections.
Scrolling = descending deeper into layers.

## Spacing
Whitespace is not empty — it is part of the experience.
- Every section is a chapter, not a row in a list.
- Never compress a layout to fit more in.
- Prefer removing content over reducing spacing.
- If a section feels tight, the fix is fewer elements, not smaller margins.

## Information Density
- Every screen communicates one idea.
- Every section has one emotional purpose.
- Every view has one primary action.
- If multiple ideas compete, remove one.
- Complexity is removed, not organized.
- Less content is usually stronger than more content.

If everything is important,
nothing is important.

## Motion
Subtle, cinematic, slow. Fade / reveal / opacity / soft parallax. No flashy animation, no startup patterns.

## UX Journey
Atmosphere → curiosity → depth → pathways → world → ecosystem. Ceremonial, not transactional.

## Emotional Hierarchy
Every page communicates in this order:
1. Atmosphere
2. Landscape
3. Human Presence
4. Story
5. Interface
Interface is never the main character. It exists only to reveal the experience.
If UI is the first thing the eye notices, the hierarchy has failed.

The interface serves the story.
The story serves the place.
The place serves the atmosphere.

## Site Structure
Pages: Home, Retreats, Mountains, Programs, Mentorship, Music, About, Connect.
Homepage: Hero → Presence → Product worlds → Featured experience → Testimonials → Community → Footer.
Products = worlds, not cards. Every section: immersive, spacious, cinematic, emotional.

## Sacred Geography
Every destination has its own emotional palette while staying inside the same design system.
Never blend two destinations' palettes in one page — see Design Anti-Patterns.

### Home
- Mood: arrival, invitation, quiet reverence, threshold-crossing, calm authority
- Materials: parchment, linen, warm stone, brushed bronze, candlelight
- Light: warm ambient glow, soft dawn-to-dusk gradient, diffused sunlight
- Photography: wide establishing shots, one human presence, layered depth
- Atmosphere: the whole ecosystem in miniature — every destination's mood present as an undertone, none dominant

### Mountains
- Mood: vastness, clarity, cold air, silence, high altitude
- Materials: stone, snow, silver, wind
- Light: cold morning sunlight, clear sky, long shadows
- Photography: large landscapes, small human presence, deep blue atmosphere
- Atmosphere: air itself becomes the subject — the space between things matters more than the things

### Kailash
- Mood: pilgrimage, sacred presence, stillness, timelessness
- Materials: black stone, aged bronze, warm gold, snow
- Light: high altitude light, golden sunrise, deep shadows
- Photography: minimal people, massive mountain, ceremonial atmosphere
- Atmosphere: the mountain is the deity — everything else recedes

### Arunachala
- Mood: inner fire, silence, grounding, devotion
- Materials: sandstone, ash, terracotta, bronze
- Light: warm sunset, dust, soft haze
- Photography: warm earth, long light, meditative atmosphere
- Atmosphere: heat without urgency — devotion that has nowhere else to be

### Annapurna
- Mood: living mountain, movement, breath, nature
- Materials: stone, mist, grass, snow, wood
- Light: cloud shadows, morning light, soft fog
- Photography: alive, organic, natural
- Atmosphere: the mountain breathes — nothing here is static

## Hero System
Hero is a portal. Never a banner.
- Photography always dominates. UI supports photography, never competes with it.
- Never terminate the Hero with a hard black gradient — see Light System.
- Mountain peaks (or the destination's core subject) must remain visible.
- Titles must never intersect important mountain silhouettes or the photograph's focal subject.
- Only one visual focal point per Hero.
- See Section Transitions below for how a Hero meets the section after it.

## Section Transitions
Section transitions are determined individually, per page, per composition — never automatically.
- Do not automatically dissolve one section into another. There is no default hand-off effect.
- Atmospheric transitions (fades, dissolves, bridging gradients) are optional. Use them only when they strengthen the composition — never as a reflex or a house style.
- Hard-coded hero dissolves are forbidden. A Hero is allowed to simply end; the next section is allowed to simply begin.
- Prefer spacing, material change, and flat tonal steps between sections over decorative blending gradients.
- When in doubt, an honest cut between two well-composed sections beats an engineered dissolve.

## Card System
Journey Cards are not products. They are ceremonial invitations.
- Large photography.
- Editorial spacing.
- Minimal borders.
- Very quiet typography.
- No marketplace feeling. No booking-card aesthetics (no price badges, no star ratings, no "Book Now").
- Hover creates depth, not movement.
- Cards should feel carved out of the page, not placed on top of it.

## Social
Hero + Footer: Telegram, Instagram, YouTube, Email.

## Testimonials
Quiet, intimate, elegant quotes. Minimal styling. Under each product category.

## Workflow Rules
1. NEVER randomly redesign sections or change colors casually
2. ALWAYS preserve consistency, reuse systems and components
3. Think modularly and cinematically
4. Preserve emotional tone — build like a premium digital studio

## Component Evolution
Components evolve. They are never redesigned from scratch.
Hero, Journey Card, CTA, Gallery, Testimonials, Guide, Timeline must remain members of one coherent design family.
Before adding a new component, ask whether an existing one can evolve to cover the need.

## Design Decision Rule
Whenever multiple visual solutions are possible, ask: does this feel more like —
- Apple?
- a travel website?
- a luxury hotel?
If yes to any of these — keep refining. Only stop when it feels uniquely like The Open Sky.

## Editing Rule
When something feels weak:
Do not add. Remove.
If removing makes it stronger, it was never needed.
The final version should feel inevitable.
Not impressive.

## When Uncertain
Choose: restraint, silence, atmosphere, simplicity, depth, rhythm.
Never choose: noise, trendiness, generic luxury, template aesthetics, overdesign.

## Design North Star
Every design decision should move toward:

Less interface.
More atmosphere.

Less explanation.
More discovery.

Less decoration.
More meaning.

Less control.
More trust.

Less software.
More place.

When uncertain, remove instead of adding.
Silence is a design tool.

## Page Rhythm
Pages unfold. Never dump information.
Every section should create the need for the next one.
Curiosity before explanation.
Emotion before information.
Silence before invitation.

## Review Checklist
Run every new page against this list before calling it done.
- Does this page breathe?
- Does photography dominate?
- Is there only one visual focal point?
- Can something be removed?
- Does this feel ceremonial instead of commercial?
- Does this look like The Open Sky?
- Would this still feel premium without animations?

## Final Principle
When two solutions are equally beautiful, choose the quieter one.
When two layouts are equally functional, choose the one that creates more presence.

The highest compliment is not:
"What a beautiful website."

It is:
"I forgot I was using a website."
